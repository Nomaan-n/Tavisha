# Tavisha 💖

A responsive personal surprise website inspired by the original reference design.

## Files
- `index.html`: landing page, photo gallery, interactive Yes/No buttons, typewriter message, and surprise reveal.
- `images/tavisha1.jpg` through `images/tavisha4.jpg`: add the four supplied photos in upload order.

## Publish with GitHub Pages
1. Upload the four images into the `images/` folder using the filenames shown above.
2. In this repository, open **Settings → Pages**.
3. Set the build source to **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
4. After the Pages build finishes, the site URL will be `https://nomaan-n.github.io/Tavisha/`.

The original `Nomaan-n/fatima` repository has not been changed by this work.
