# Tavisha 💖
A responsive personal surprise website with four photos in upload order.

## Publish on GitHub Pages
1. Upload `index.html` and the `images` folder to the root of your `Nomaan-n/Tavisha` repository.
2. Open Settings → Pages.
3. Select `Deploy from a branch`, choose `main` and `/ (root)`, then Save.
4. The public URL should be https://nomaan-n.github.io/Tavisha/ once deployment completes.
